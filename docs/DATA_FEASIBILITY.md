# 데이터 접근 가능성 조사

조사일: 2026-09-15 (Asia/Seoul)

## 확인된 사항

공식 OpenDART 개발가이드에서 다음을 확인했다.

- [공시검색 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)는 `list.json`/`list.xml`을 제공하며 인증키가 필수다. `last_reprt_at=N`(기본값)이 정정보고서를 포함한 제출 보고서 전체 검색이고, 회사 고유번호가 없으면 검색 기간은 3개월로 제한된다. 페이지는 `page_no`, `page_count`(최대 100)로 처리한다.
- 목록 결과에는 14자리 접수번호, 보고서명, 접수일자와 뷰어 URL 구성 규칙이 있으나, 이것만으로 이전 공시와 동일 계약이라고 확정할 수 없다.
- [공시서류 원본파일 API](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019003)의 경로명은 `document.xml`이지만 정상 출력 형식은 **ZIP 바이너리**다. 브라우저가 `.xml` 확장자로 저장할 수 있다는 공식 주의사항도 있다.
- 같은 원본 API가 오류 시 `status`/`message` XML을 반환할 수 있다. 특히 `013`(조회 데이터 없음)과 `014`(파일 없음), 인증·제한·점검 오류를 ZIP과 Content-Type/파일 시그니처로 구분해야 한다.

## 대표 정정쌍 3건 조사 결과

## 목표 양식군과 업로드 경로

첫 목표는 한국거래소 수시공시 `단일판매ㆍ공급계약체결`과 그 `[기재정정]` 표 양식군이다. 실제 원문을 확보하지 못해 현재 “지원 확인 양식”은 0개이며, 합성 HTML은 구조 설계 입력일 뿐 양식 지원 증거가 아니다.

1단계 업로드 대상 `.html`/`.htm`, `.xml`, `.txt`와 OpenDART 원본 `.zip`의 안전한 메모리 내 로더를 구현했다. 원본 파일명, 수집 시각, SHA-256, 사용자 제공 접수번호와 출처 검증 여부를 문서 모델에 보존한다. HTML은 렌더링·스크립트 실행 없이 구조만 읽는다. ZIP 경로 이탈·엔트리 수·압축 해제 총량·압축비와 XML DTD/외부 엔티티 선언, 단일 파일 크기를 제한한다. PDF/OCR은 범위 밖이다.

## 미확인·한계

- 인증키 호출, 요청 제한의 실제 응답, 정상 ZIP의 내부 파일명/인코딩은 미검증이다.
- 목표 공시가 원본 API에 실제 존재하는지, 공개 뷰어의 표 구조가 원본 ZIP과 같은지는 미검증이다.
- 정정표와 정정 후 본문의 일관성, 최초→반복 정정 관계 표현은 실제 자료로 미검증이다.
- 공개 원문의 재배포 조건은 확인하지 않았으므로 실제 파일을 fixture로 커밋하지 않는다.
- 실제 DART ZIP 내부 구조와 인코딩은 미확인이라, 현재 파서는 synthetic `contract`/`correction-table` 표와 명시적 `레이블: 값` 텍스트만 지원한다. 미지원 표는 추측하지 않고 `UNSUPPORTED_FORMAT`으로 반환한다.

## 실제 검증 재개 절차

비밀 설정에 DART 키가 제공되면 회사·기간을 제한하고 `last_reprt_at=N`으로 페이지 전체를 조회한다. 후보별 접수번호를 목록 응답 그대로 기록한 뒤 원본 API 응답이 ZIP인지 오류 XML인지 판별한다. 정정 문서가 가리키는 원문, 계약 내용·상대방·계약일 등을 함께 대조한 경우에만 같은 계약으로 확인한다.
