# 프로젝트 명세

이 문서는 루트의 [`PROJECT_BRIEF.md`](../../PROJECT_BRIEF.md)를 0단계 구현의 정본으로 보존·연결한다. 원문 기획서는 수정하거나 이동하지 않았다.

## 제품 목표

단일판매·공급계약의 기재정정 전후를 비교하고, 한 기업·한 계약·한 한국어 메모에서 바뀐 사실과 연결되는 주장을 찾아 문장별 영향 검토표와 근거 있는 수정안을 만든다. 서버가 검증한 제안 중 사용자가 승인한 사실 수정만 기존 메모를 보존한 새 버전으로 저장한다.

## 데이터 모델 초안

- `FilingDocument`: 내부 문서 ID, 접수번호(선택), 실제/사용자 업로드/합성 출처, 수집 시각, 해시, 원문 참조, 파서 버전.
- `EvidenceBlock`: 문서 해시, 표/행/셀 또는 문단 ID, 원문 문자열.
- `ContractRelation`: 문서 관계, 계약 식별 근거, 확정/후보/사용자 확인 상태.
- `StructuredField`: 원문 값, 정규화 값, 단위·통화·기준일·회계연도·연결/별도·부가세, 값 상태, 근거 ID.
- `FieldChange`: 기준 문서와 대상 문서, 직전/누적 비교, 의미 기준 호환성, 전후 근거.
- `Memo` / `MemoVersion`: 불변 원문 버전, 해시, 작성/평가 출처.
- `Claim`: 문장/절 범위, 대상 계약, 사실/계산/전망, 현재/역사/가정 시점.
- `Impact`: `DIRECT_FACT_CHANGE`, `DERIVED_VALUE_CHANGE`, `INTERPRETATION_REVIEW`, `NO_IMPACT`, `UNRESOLVED`, 근거와 부족 자료.
- `Proposal`: 검토·메모·근거·제안 버전에 결합된 교체 범위와 상태.
- `ReviewState`: review/thread ID, 입력 해시, 관계, 변화, 주장, 근거, 보류, 행동 이력, 호출 한도, 승인 대상 버전.

`미공개`, `유보`, `빈 값`, `0`, `파싱 실패`는 서로 다른 상태다. 숫자는 `Decimal` 또는 원 단위 정수, 날짜는 날짜 타입을 사용한다.

## 상태 전이 초안

`입력 고정 → 공시 확보/관계 확인 → (부족: 자료 조회 또는 사용자 대기/재개) → 정규화/변경 계산 → 주장/영향 분석 → 근거 검증 → 수정안 및 보류 → 사용자 검토 대기 → 서버 승인 검증 → 새 메모 버전 저장`

실패·미검토는 `NO_IMPACT`로 변환하지 않는다. interrupt 재개로 노드가 재실행될 수 있으므로 저장은 멱등 키와 트랜잭션으로 보호한다.

## 1~6단계

1. 실제 원문 형태 파싱, 근거 위치 보존, 계약 관계와 필드 변경/계산 검증, 안전한 업로드.
2. 교체 가능한 주장 추출·영향 분석·수정안 인터페이스와 분리된 평가 데이터.
3. StateGraph 조건 분기, 허용된 보완 행동, 영속 체크포인터, interrupt/resume.
4. 제안별 승인, 버전·근거 재검증, 부분 적용, 멱등한 새 메모 버전 저장.
5. 수동 업로드와 선택적 DART 입력, FastAPI 전체 흐름, 한국어 Streamlit 화면.
6. 고정 평가와 회귀 검증, 실제/합성 및 fake/실제 LLM 분리 보고, 시연 자료.

상세 완료 조건은 정본 기획서와 [`CODEX_PROMPTS.md`](../../CODEX_PROMPTS.md)를 따른다.

## 1단계 구현 결정

- 문서, 증거 블록, 구조화 필드, 정정 항목, 추출 문제, 관계 후보, 필드 변경, 비율 계산, 연쇄 비교를 별도 Pydantic 스키마로 분리했다.
- 증거 ID는 문서 ID와 표/행/셀 또는 문단 위치를 포함하고, 각 블록은 원문 SHA-256과 원문 문자열을 보존한다.
- 지원 표 ID를 명시적으로 제한한다. 지원하지 않는 구조나 불완전 값은 추정하지 않고 문제/값 상태로 반환한다.
- 정정표의 `정정 후`와 본문, `정정 전`과 기준 본문이 충돌하면 해당 필드 변경은 `UNRESOLVED`다.
- 자동 계약 확인은 명시적 정정 링크와 계약 내용, 상대방 또는 시작일이 일치해야 한다. 검증된 연쇄 관계는 최초 기준 누적 비교에 사용할 수 있다.
- 기재 비율과 서버 `Decimal` 재계산을 분리하며 서버 결과는 반올림하지 않는다.
